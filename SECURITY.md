# Security Policy

## Educational & Competition Notice
This capture-the-flag platform deliberately hosts intentionally vulnerable endpoints, LLM agent personas, and internal service gateways for educational security challenges and red team competitions. 

## Host Environment Boundaries
All vulnerabilities should be constrained strictly within the running application container boundaries. If you identify unexpected container escape primitives, host file system traversal, or uncontained kernel-level issues:
- **Do not** file public issues or publicly disclose vulnerabilities.
- Report the issue directly to: **btsiamouras@gmail.com** or via [LinkedIn](https://www.linkedin.com/in/vasilis-tsiamouras/).
